## System Overview

**TheAssistant** is an AI-powered personal assistant built with .NET 8, Microsoft.Extensions.AI, and Azure services. It communicates via Signal messaging and provides multiple capabilities through specialized agents.

### Core Capabilities
- ?? **Agenda Management** - Calendar events, meetings, birthdays
- ??? **Weather** - Multi-city weather forecasts (10 Dutch cities)
- ?? **Azure Costs** - Cost analysis and reporting
- ?? **Daily Updates** - Coordinated summaries from multiple agents

### Technology Stack
- **.NET 8** - Core runtime
- **Azure Functions** - Serverless compute
- **Azure Service Bus** - Message queueing
- **Azure OpenAI** - LLM capabilities
- **Microsoft.Extensions.AI** - Unified AI abstraction layer
- **Signal** - User interface
- **Azure Key Vault** - Secrets management
- **Application Insights** - Monitoring & logging

### Tool Definition Pattern

```csharp
// 1. Agent defines tool methods with [Description] attributes
[Description("Gets Azure costs for a specific date range")]
public async Task<string> GetCostsForPeriod(
    [Description("Start date in format YYYY-MM-DD")] string startDate,
    [Description("End date in format YYYY-MM-DD")] string endDate)
{
    // Validation
    if (!DateTime.TryParse(startDate, out var start))
        return JsonSerializer.Serialize(new { error = "Invalid start date" });
    
    // Business logic
    var costs = await _adapter.GetCostsForPeriod(start, end);
    
    // Return JSON
    return JsonSerializer.Serialize(costs);
}

// 2. Agent registers tools in HandleAsync
var tools = new List<AITool>
{
    AIFunctionFactory.Create(GetCurrentMonthCosts),
    AIFunctionFactory.Create(GetPreviousMonthCosts),
    AIFunctionFactory.Create(GetCostsForPeriod)
};

// 3. Pass tools to chat service
var reply = await _chat.GetChatMessageContentAsync(
    history,
    new ChatOptions { Tools = tools },
    cancellationToken);
```

## Key Design Patterns

### 1. CQRS (Command Query Responsibility Segregation)
- Commands: `HandleQueuedMessageCommand`, `HandleReceiveMessagesCommand`
- Handlers: `*CommandHandler.cs` in Core/Messaging/

### 2. Dependency Injection
- All services registered in `Module.cs` files
- Scoped to HttpContext or Function execution

### 3. Adapter Pattern
- Service Adapters wrap external APIs
- Provide consistent interfaces to Core

### 4. Strategy Pattern
- RoutingAgent: Selects appropriate agents
- AgentOrchestrator: Executes based on execution plan

### 5. Chain of Responsibility
- Message flows through multiple layers
- Each layer transforms/enriches data

### 6. Repository Pattern
- TokenStore, ServiceBus abstractions
- Azure Key Vault as backing store
